# PizzaHub Server

REST API for PizzaHub, a pizza ordering and delivery platform with Customer,
Vendor and Admin roles. Built with Express.js and MongoDB.

## Installation
```bash
git clone https://github.com/MahbubSifat/pizzahub-server
cd pizzahub-server
npm install
```

## Run Locally
1. Copy `.env.example` to `.env` and fill in the values.
2. Run `npm run dev`.
3. Open `http://localhost:5000/api/health`.
